# MUNDO X

## Buscador Mundial de Cuentas de X

MUNDO X es un buscador y directorio mundial de cuentas de X (Twitter), organizado por país, categoría, idioma, tipo de cuenta y relevancia.

### Objetivo

Encontrar rápidamente cuentas de X relevantes de todo el mundo.

### Categorías iniciales

- Geopolítica
- Política
- Noticias
- Tecnología
- Deportes
- Historia
- Geografía
- Economía
- Finanzas
- Ciencia
- OSINT
- Defensa
- Periodistas
- Instituciones
- Organizaciones

### Funciones previstas

- Búsqueda por @usuario, nombre, país o tema.
- Filtros por país, categoría, idioma, tipo de cuenta y verificación.
- Ranking de cuentas por relevancia.
- Fichas individuales de cada cuenta.
- Enlace directo a X.
- Estadísticas por país y categoría.
- Arquitectura preparada para crecer sin perder el enfoque principal en cuentas de X.

### Tecnología
